# AoAoEnergy 私人修复版

原作者：Loskh

将强化药（爆发药）特效替换为充满活力的 RGB 能量光效。本版本适配国服版本 7.56 与 Dalamud API 15，并增加光效高度调节、按角色记忆、即时预览及清除当前光效功能。

## 安装与更新

以下步骤以已经安装并能正常使用卫月框架（Dalamud）为前提。

1. 在游戏中输入 `/xlsettings`。
2. 打开“实验性功能”，在“自定义插件仓库”中添加：
   `https://raw.githubusercontent.com/Ryouta-Z/FF14_AOAOenergy_fixed/master/repo.json`
3. 保存设置后打开 `/xlplugins`，搜索并安装 `AoAoEnergy`。

通过该仓库安装后，新版本会显示在 Dalamud 的插件更新中，不需要重新下载或接收 ZIP。

> 请勿同时安装原作者版本与本私人修复版，两者使用相同的插件内部标识。
